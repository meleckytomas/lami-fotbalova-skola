# Lamiho Fotbalova Skola

Jednoducha staticka vzdelavaci hra pro procvicovani matematiky, cestiny, anglictiny a prvouky.

## Spusteni lokalne

```bash
python3 -m http.server 8000
```

Potom otevrit:

```txt
http://127.0.0.1:8000/
```

## Publikovani

Projekt je staticky web a muze bezet pres GitHub Pages primo z vetve `main`.
